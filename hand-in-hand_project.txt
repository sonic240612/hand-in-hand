hand-in-hand
ai 협업 세션

만들게 된 계기: ai를 이용하여 프로젝트를 진행하는데, github를 사용하기엔 너무 귀찮고, 실시간으로 진행 상황과 결과물을 확인하고 싶고, 상대방 컴퓨터에 데이터 등 필요한 파일들을 다시 내 컴퓨터에 받는 것도 시간이 오래 걸림. 차라리 둘 다 ai 에이전트나 하네스 (codex, claude code 등)을 사용하고 있다면, 같은 프로젝트 세션에서 같이 작업 -> 기준이 되는 기기의 프로젝트 세션에서 작업이 가능 하면 된다. -> 내가 올린 작업은 내 할당량을 사용하고, 상대가 올린 작업은 상대방 자신의 할당량을 사용한다.

같은 세션을 다른 기기들, 다른 계정들에서 동일하게 작업 가능하도록.
왜 이래야 하나?  -> 받아서 이어서 하려면 그거 분석하는데에 토큰 녹아서 아깝다.
하나의 세션에 여러 계정(codex, claude code 등)을 연결해서 개발 가능 -> 하나의 프로젝트를 여러 명이 동시에 개발 가능함.
진행 상황도 같이 볼 수 있고, 결과물도 실시간으로 확인 가능함.

여러 기기에서 하나의 workspace를 공유하며 작업 가능.
workspace는 기기 하나를 정해서 작업.
처음 workspace를 생성하고 세션을 생성한 기기에서 초대 링크를 통해 다른 사람들을 초대 가능.
workspace를 한군데로 통일해서 파일 다시 다운받고 그런거도 없고
한쪽 로컬 저장소에 들어가 있으면 그냥 거기 있는 파일들 불러와서 쓰면 됨.
필요한 파일만 한두개씩 불러와서 작업.
그냥 컴 켜두기만 하면 workspace로 지정한 로컬 저장소 사용 가능

localsend 라는 프로그램 같은 것들을 응용하면 될 듯?
파일을 쉽고 빠르게 주고 받을 수 있음. 혹은 더 좋은 방법이 있다면 그걸 사용해도 됨.
